🌟 About the Project

G.I APK Builder — Golden Edition is an Android application project focused on making APK building workflows accessible through a mobile-friendly experience.

The project uses Kotlin, Jetpack Compose, Gradle, and GitHub Actions to provide an Android app interface and a cloud-based build workflow.

The goal is to develop a practical tool that allows users to manage Android projects and build APK files without requiring a full Android development environment on their phone.

«🛠️ Project status: Under development. Features and build workflows may change as development continues.»

☁️ Build an APK with GitHub Actions

The repository includes a GitHub Actions workflow for building the G.I APK Builder Android application.

Step 1 — Open Actions

Visit:

"G.I APK Builder — GitHub Actions" (https://github.com/gikoko611/GI-APK-Builder-Engine-/actions)

Step 2 — Select the Workflow

Choose:

"G.I APK Builder - Golden Edition"

Step 3 — Run the Build

1. Open Run workflow.
2. Select the "main" branch.
3. Start the workflow.
4. Wait for the build to finish.

Step 4 — Download the APK

If the workflow succeeds:

1. Open the completed workflow run.
2. Find the Artifacts section.
3. Download "gi-apk-builder-debug".
4. Extract the downloaded ZIP.
5. Locate "app-debug.apk".

Note: The APK is a debug build. It is not a release-signed production APK.

🔐 Security

When connecting the app to GitHub or other external services:

- Never publish personal access tokens or API keys.
